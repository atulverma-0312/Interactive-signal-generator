# Interactive-signal-generator
Generate sine, cosine, square, triangular, ramp and impulse signals.

A Python-based interactive web application built using **Streamlit, NumPy, SciPy, and Matplotlib** to generate and visualize different types of signals.

### ✨ Features
- Generate Sine, Cosine, Square, Triangle, Ramp, and Exponential signals.
- Unit Step and Unit Impulse generation.
- Continuous-Time and Discrete-Time visualization.
- Amplitude, Frequency, and Phase adjustment.
- Time Shifting and Time Scaling.
- Download signal data in CSV format.

### 🛠️ Technologies
- Python
- Streamlit
- NumPy
- SciPy
- Matplotlib
- Pandas

### 🚀 Run Locally

```bash
streamlit run project.py
```

### 🎓 Concepts Covered
Signal Generation, Time Shifting, Time Scaling, Amplitude Scaling, and Signal Visualization.

**Developed as an academic project for Signal and Systems.**
